# prestacioncontable

Sistema web para la gestión y el cálculo de prestaciones sociales.

Consulta [LEEME_INSTALACION.md](LEEME_INSTALACION.md) para instalarlo y [LEEME_EJECUCION.md](LEEME_EJECUCION.md) para ejecutarlo.

## Primer acceso

Al abrir el sistema por primera vez, `login.php` solicitará crear la cuenta administradora inicial. El administrador puede crear cuentas adicionales con rol **Administrador** o **Usuario** desde el módulo **Usuarios**.
